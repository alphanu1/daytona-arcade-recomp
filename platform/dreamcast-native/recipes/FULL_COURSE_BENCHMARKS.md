# Dreamcast full-course benchmark replays

Four scripted runs cover the game's three circuits and the attract loop. Use them to compare frame rate and
gameplay between builds. "Medium" is not a circuit name in the game: the middle circuit is **Advanced**.

| Benchmark | What it plays | ELF (recipe `--elf` output) | Checkpoints |
| --- | --- | --- | --- |
| Beginner | Fast race, 8/8 laps, finish, podium and results | `elf/stats/` | 259 |
| Advanced | 4 laps to 3rd place, podium and results | `elf/stats-advanced-finish/` | 320 |
| Expert | 2 laps to 3rd place, podium and results | `elf/stats-expert-finish/` | 345 |
| Attract | The attract loop over all three circuits (cinematic, V.R. demo, title), 3 loops | `elf/stats-attract/` | none |

The ELFs and assets are built by `zsh platform/dreamcast-native/recipes/build_assets.sh ROM OUTDIR --music ARCHIVE --elf`;
see [README.md](README.md) for the ROM, music and toolchain requirements. The Advanced and Expert inputs are
[inputs-advanced-finish.txt](inputs/inputs-advanced-finish.txt) and
[inputs-expert-finish.txt](inputs/inputs-expert-finish.txt); their comments record the lap counts and finish ticks.
The Beginner fast race is generated by the recipe's `race_script` step. The expected checkpoint rows are written to
`OUTDIR/work/script*/expected-checkpoints-*.txt`.

## Running one

Runs must be serial (the runner takes the shared console lock). From the repository root:

```sh
zsh build/hw-tools/run_hw.sh expert-full OUTDIR/elf/stats-expert-finish/bin/*.elf OUTDIR/assets-ssfar4f
python3 platform/dreamcast-native/tools/drop_log_report.py build/hw-tools/hw/console-expert-full.log
```

Each run writes `build/hw-tools/hw/console-<name>.log` and `run-<name>.out`. A run counts as evidence when it ends
with `Program returned 0` and its `CHECKPOINT` rows equal the expected file (0 differing). The drop log report gives
the late frames, each with its cause (update, registration, PVR, load) and tick.
